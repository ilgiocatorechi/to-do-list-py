# Terminal To-Do List (Python)

A simple Python program to manage a to-do list from the terminal. Data is saved in a local file called `tasks.txt`.

## How to Use

1. Open the CMD in `/to-do-list-py-main`
2. Run `python .\todo` in the CMD
3. Follow the menu to add, remove, or view tasks
4. Tasks are automatically saved when exiting

## Requirements

- Python 3 installed
